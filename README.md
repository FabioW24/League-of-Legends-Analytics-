# League of Legends Performance Data

> 🚧 Work in Progress

This is my first independent Python project and is currently a work in progress.

The application is designed to fetch player, champion and performance data from the Riot Games API and store it in a PostgreSQL database. The project is currently designed to run locally on my own machine and is not yet set up for public use or deployment.

The code is available in this repository for anyone who would like to inspect the implementation and follow the development of the project.

## Planned Improvements

Some of the features and improvements I am planning for future versions include:

- Development of a user-friendly GUI
- Improving the overall performance and efficiency of API requests
- Further optimization of the database structure
- Improved error handling and input validation
- Making the application easier to set up and use on other systems
- Further testing and refinement of the application

## Current Status

The project is functional in my local environment, but it is **not yet ready for external users**. At the moment, there is no graphical user interface, so interaction with the application is mainly done through the existing Python functions.

The goal is to gradually turn the current prototype into a more polished and user-friendly application.
